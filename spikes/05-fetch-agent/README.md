# Mulligan Guardian

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Mulligan Guardian runs an agent's task through the Mulligan gateway, which records every action on Postgres, GitHub and Notion. It tells you what happened and what is held for approval, and it rewinds the whole session when you say "rewind".
